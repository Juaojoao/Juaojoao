## 👨‍💻 Sobre mim

Sou Desenvolvedor Full Stack com maior foco em **desenvolvimento backend e engenharia de software**.

Trabalho principalmente com **C# / .NET** e também com o ecossistema **Node.js / NestJS** para construção de APIs e serviços backend. No frontend, utilizo **Next.js e TypeScript** para desenvolver aplicações web modernas.

Tenho interesse especial em entender o software além da implementação: **arquitetura, modelagem de dados, design de APIs, infraestrutura e decisões técnicas** que tornam sistemas mais fáceis de evoluir e manter.

Atualmente venho aprofundando meus conhecimentos em **Arquitetura de Software, System Design, Docker, Kubernetes e bancos de dados**.
