## 👨‍💻 Sobre mim

Sou **Desenvolvedor Full Stack** com maior foco em **Backend e Engenharia de Software**.

Trabalho principalmente com **C# / .NET** e com o ecossistema **Node.js / NestJS** no desenvolvimento de APIs, serviços e sistemas de negócio. No frontend, utilizo **Next.js, React e TypeScript** para construção de aplicações web modernas.

Tenho interesse especial em compreender o software além da implementação, estudando **Arquitetura de Software, System Design, modelagem de dados, design de APIs, infraestrutura e boas práticas de desenvolvimento**.

* ⚙️ Desenvolvimento de APIs e aplicações backend com **C# / .NET e NestJS**
* 🌐 Desenvolvimento frontend com **Next.js, React e TypeScript**
* 🗄️ Bancos de dados com **PostgreSQL, SQL Server, Prisma e Redis**
* 🐳 Containerização e ambientes com **Docker**
* ☸️ Aprofundando conhecimentos em **Kubernetes**
* 🏗️ Interesse em **Arquitetura de Software, System Design e sistemas distribuídos**
